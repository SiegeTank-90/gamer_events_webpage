<h1>###Game Queue###</h1>
<p>A demo product example of an aid to find players of your favorite tabletop game to schedule for local meetup at stores in your area.</p>
<h1>###Tech Stack (MERN)###</h1>
<p>Frontend: (React)</p>
<p>Backend:(Node, Express)</p>
<p>Database: (MongoDB)</p>
<h1>###Installation###</h1> 
<p>To run the startup scripts, you will want to install node which you can follow the instructions from the below link to do. 
https://nodejs.org/en/download
With node installed you can clone the repository</p>
<br>
<p>Open two terminal consoles, 
You will want to navigate to the app_client_side/gamer_events folder and app_server respectively in the two consoles. Then “npm start” 
Once both applications are running you will be able to see the application on localhost://3000 in your web browser. <p>
<br>
